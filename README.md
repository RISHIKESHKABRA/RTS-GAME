# Python 2D RTS Game

A lightweight 2D Real-Time Strategy engine written in Python using `pygame`.

## Features
- **Resource Gathering**: Units automatically shuttle gold from resource nodes to the nearest base.
- **Multi-Unit Control**: Box-drag marquee selection and point-and-click movement.
- **Building Placement**: Preview ghost building placement with cost requirements.

## Controls
- **Left Click + Drag**: Select multiple units.
- **Right Click**: Issue movement commands or target resource nodes to harvest.
- **B Key**: Toggle base construction preview mode.
- **Esc Key**: Cancel build mode.
